## Platform references checked

- [Chrome content scripts](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts): isolated-world content scripts, DOM access and extension messaging.
- [Chrome extension storage](https://developer.chrome.com/docs/extensions/develop/concepts/storage-and-cookies): IndexedDB is available to extension service workers; content-script web storage belongs to the host page. This implementation keeps canonical data in the extension-origin worker.
- [Chrome tabs API](https://developer.chrome.com/docs/extensions/reference/api/tabs): API boundary for extension pages and the service worker. Screenshot capture is deliberately not implemented.

Platform documentation was checked while implementing, rather than assuming historical conversation statements still described the current APIs.
